# Натальная карта — демо VK Mini App

Рабочее название интерфейса — **«Свой круг»**. Главная страница теперь
`public/orbit.html` + `public/orbit.css` + `public/orbit.js`; прежний
`public/index.html` сохранён для сравнения. Внизу нового интерфейса четыре раздела:
«Карта», «День», «Друзья», «12 глав».

> **Важно про оригинальность.** Первая версия этого интерфейса была сделана «по референсу»
> конкурента (`vk.com/app54701582`) и фактически повторяла его: название, слоган, тексты
> формы и кнопок, шрифтовую пару (Prata + Golos) и кремово-золотую палитру.
> Это было ошибкой: правила VK Mini Apps (п. 4.1.6.1) прямо запрещают приложения,
> копирующие элементы интерфейса уже размещённых приложений, — **«Приложения-клоны
> не допускаются к Публикации»**. Интерфейс переписан полностью: своя тёмная
> «ночная» палитра, другая шрифтовая пара (Cormorant + Manrope), свои формулировки
> и другая логика подачи. При доработке **не возвращайте** заимствованные тексты и стиль.

Первая версия **без реальной монетизации** — для показа руководству и проверки воронки.
69 голосов пока только подпись на демо-кнопке: списания и права доступа нет.
Ежедневная карточка и дата рождения друга сохраняются только в браузере;
уведомления, реферальные бонусы, подарочная оплата и диалог с практиком не подключены.

## Что уже работает

- Приложение открывается в ВК (инициализация `vk-bridge`)
- **Проверка подписи параметров запуска на сервере** — ключ не попадает в браузер
- Ввод данных: имя, дата (с маской), время (необязательно), город (автокомплит)
- **Справочник ~160 городов**, включая Череповец; если города нет — **ручной ввод координат**
- Расчёт натальной карты: 10 тел через Astronomy Engine; при известном времени
  рождения — Асцендент и 12 домов Плацидуса через Caelus (MIT). На высоких
  широтах применяется цельнознаковая система; без времени дома не выводятся.
  Исторический UTC-сдвиг определяется по координатам и дате рождения
- **Символы зодиака** (♈–♓) — через symbol-шрифты, см. раздел про грабли ниже
- **Годовой атлас**: обложка со словарём → индивидуальный SVG-круг с домами →
  обзор года → 12 глав с точными личными аспектами и лунными фазами → итог года.
  Сохраняется через системную печать в PDF
- **Работает и с LLM, и без ключа**: 4 AI-запроса по 3 месяца;
  при сбое — расчётный демо-текст. Режим фиксируется в ответе API и логах
- Кнопка экспорта рассчитанных дат в `.ics` для календаря телефона;
  импорт зависит от календарного приложения и требует действия пользователя
- Пейволл с имитацией оплаты — для демонстрации полного пути
- Новый игровой интерфейс с анимацией, четырьмя разделами и учётом настройки
  «уменьшить движение»; мобильная, планшетная и настольная компоновки,
  мягкое появление глав при прокрутке; атлас внутри раздела «12 глав»

## Режимы текстов

Разбор собирается в одном из двух режимов, переключается автоматически:

| Условие | Что получится |
|---|---|
| `KIE_API_KEY`, `DEEPSEEK_API_KEY` или `LLM_API_KEY` задан | AI-текст по рассчитанным положениям и аспектам |
| Ключа нет или сервис не ответил | Расчётный демо-текст, не готовый платный продукт |

Проверить, какой режим сработал, можно в ответе API: поле `report.source`
(`llm` или `template`).
Для годового атласа смотрите `annual.source` (`llm` или `calculated-demo`).
Старый `/api/report` ещё обслуживает бесплатное толкование Большой тройки;
его `report.forecastSource` не относится к новому годовому атласу.

## Что нужно от тебя, чтобы открыть в ВК

### Веб, VK Mini Apps и PWA — три режима одного интерфейса

Фронтенд уже является веб-приложением: `public/orbit.html` открывается в браузере, внутри VK Mini Apps и, после публикации на HTTPS, может быть добавлен на домашний экран как отдельная PWA-оболочка. Манифест и иконка лежат в `public/manifest.webmanifest` и `public/app-icon.svg`. Отдельная PWA «ВКонтакте» на iPhone — это оболочка самого VK; наш мини-апп должен проверяться внутри неё, ему не нужен второй пакет для App Store.

Для этого проекта недостаточно загрузить только папку `public/` на статический хостинг VK: `/api/chart`, `/api/annual`, геокодер и генерация текста выполняются Node-сервером. Для демонстрации нужен публичный HTTPS-адрес **всего сервера** или раздельный фронтенд и API с корректным проксированием. Текущий код использует same-origin запросы `/api/*`, поэтому первый вариант проще.

Манифест не означает офлайн-режим или веб-push. Персональные отчёты и данные рождения намеренно не кэшируются service worker. Перед реальным запуском нужны постоянный хостинг, защита API проверенной подписью VK/авторизацией, серверное хранение прав на покупку и проверка на iPhone Safari, PWA VK, Android VK и desktop VK. Пока данные и «покупка» хранятся только в браузере и демо нельзя считать платёжным продуктом.

### Шаг 1. Создать приложение

1. Зайти на **dev.vk.com** → «Создать приложение»
2. Тип — **Мини-приложение**, платформа — **Web**
3. Получить **APP_ID** (число)

### Шаг 2. Взять защищённый ключ

В настройках приложения: **Разработка → Ключи доступа → Защищённый ключ**

Вписать его в `.env` как `VK_SECURE_KEY`. **Никому не показывать** — это ключ подписи.

### Шаг 3. Сделать приложение доступным из интернета

ВК грузит приложение по публичному HTTPS-адресу. Локальный `localhost` не подойдёт.

**Вариант для теста (бесплатно) — Cloudflare Tunnel:**

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:3000
```

Команда выдаст адрес вида `https://random-name.trycloudflare.com` — его и указываем в ВК.

### Шаг 4. Прописать адрес в настройках приложения

**Настройки → Основные → URL мини-приложения** → вставить адрес из шага 3.

**Настройки → Основные → Официальное сообщество** → выбрать сообщество (можно своё, для теста).

### Шаг 5. Открыть

```
https://vk.com/app<ТВОЙ_APP_ID>
```

Если сверху появилась зелёная плашка «Запуск из VK подтверждён» — подпись работает.

## ⚠️ Грабли со символами зодиака — не наступать повторно

Символы зодиака (♈–♓) **отсутствуют** в `-apple-system`, `BlinkMacSystemFont`,
`Segoe UI`, `Roboto` и большинстве обычных текстовых шрифтов. Там, где глифа нет,
браузер рисует **пустой квадрат**.

Это проверено замером ширины глифа в canvas:

| Шрифт | Глифов из 12 |
|---|---|
| `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto` | **0** ❌ |
| `Apple Symbols` | 12 ✅ |
| `Segoe UI Symbol` | 12 ✅ |
| `Noto Sans Symbols 2` | 12 ✅ |
| `DejaVu Sans` | 12 ✅ |

Поэтому в CSS есть класс `.zy` с **обязательным** symbol-шрифтом в стеке:

```css
.zy {
  font-family: "Apple Symbols", "Segoe UI Symbol", "Noto Sans Symbols 2",
               "Noto Sans Symbols", "DejaVu Sans", "Arial Unicode MS",
               "Cormorant", serif;
}
```

**Не убирайте symbol-шрифты из этого стека** — символы снова превратятся в квадраты.

> История: в двух предыдущих итерациях проблема «решалась» неправильно — сначала
> отказом от символов в пользу дублирующих аббревиатур (`ОВЕН ОВН`), потом
> самодельными SVG-иконками, которые на 18 пикселях выглядели как квадраты.
> Правильное решение — просто задать шрифт, в котором эти глифы есть.


## ⚠️ Известные ограничения (важно для продакшена)

### 1. Расчёт и интерпретация — разные вещи

Сервер использует `src/astro.js` и Astronomy Engine 2.1.19 для вычисления
геоцентрических долгот десяти тел. Caelus 0.25.0 (MIT) считает Асцендент и
дома Плацидуса при известном времени рождения. На высоких широтах Caelus
переключается на цельнознаковые дома. Старый упрощённый `src/chart.js` оставлен
для сравнения; сервер его движок больше не вызывает. Нужны независимые
контрольные карты и проверка точности до коммерческого запуска. Астрономический
расчёт не подтверждает прогностические выводы.

Контроль Марка (08.04.1996, 11:13, Череповец): UTC 07:13; Асцендент
112.539°, куспид II дома 124.357°, MC 341.557°. Диагностический прогон
Swiss Ephemeris 2.10.03 дал те же значения в пределах 0.001°.

Swiss Ephemeris не подключён; его применение требует отдельной проверки
условий AGPL или коммерческой лицензии.

### 2. Часовые пояса — главная дыра

Сервер теперь определяет IANA-зону по координатам и переводит локальное время
в UTC по историческим правилам этой зоны. Например, Череповец 08.04.1996
11:13 → 07:13 UTC. Поле текущего смещения в старом интерфейсе больше не
используется для расчёта. Для пограничных координат, старых дат и спорных
переходов часов нужен независимый контроль.

**Это неверно для большинства дат:**

| Период | Реальность |
|---|---|
| до 1930 | местное солнечное время, пояс свой в каждом городе |
| 1930–1991 | декретное время (+1 к поясу) |
| 1981–1991 | + летнее время |
| 1992–2011 | пояс + летнее время (до 2011) |
| 2011–2014 | постоянное летнее время |
| с 2014 | пояс без летнего времени |

При переходе часов одно локальное время может существовать дважды; демо
выбирает первое совпадение и помечает неоднозначность в ответе API.

### 3. Геокодер — демо-справочник

В `src/cities.js` лежит демо-справочник городов. Для продакшена — GeoNames или
свой справочник по РФ.

### 4. Монетизации нет

Намеренно. Пейволл — экран-заглушка. Подключение `VKWebAppShowOrderBox`
требует, чтобы монетизацию закрепил владелец ИП в Кабинете выплат
(по документации ВК — только создатель приложения).

## Проверка подписи — не выключать

`src/launch-params.js` реализует алгоритм из документации ВК:
отсортировать `vk_*` → склеить через `&` → HMAC-SHA256 → base64
с заменой `+`→`-`, `/`→`_` и обрезкой `=`.

Без этой проверки любой подделает `vk_user_id` и получит чужие данные.
По правилам ВК (п. 1.2.2) валидация подписи обязательна.
